Simple Types

Simple types represent scalar values: strings, numbers, booleans, dates, and a few special singleton types. The library exports pre-defined instances for the most common ones. You do not call a factory to get them — you import them directly and use them as property types.

Pre-defined instances​

import {
  string, number, boolean, date,
  nullType, undefinedType, voidType
} from '@aelastics/types'
ExportTypeScript value typeDescription
stringstringAny string value
numbernumberAny number value
booleanbooleantrue or false
dateDateJavaScript Date object
nullTypenullThe single value null
undefinedTypeundefinedThe single value undefined
voidTypevoidUsed for properties with no meaningful value

These are system types. You cannot add validators to them directly. Use derive() to create a constrained variant instead.

Optional convenience instances​

import { optionalString, optionalNumber, optionalBoolean } from '@aelastics/types'

These are pre-defined optional(string), optional(number), and optional(boolean) instances. They are useful when you want to mark a single property as optional without calling optional() yourself.

Literal types​

literal(value) creates a type that only accepts exactly one value. The value must be a string, number, or boolean.

import { literal } from '@aelastics/types'

const active   = literal('active')
const inactive = literal('inactive')
const zero     = literal(0)

Literal types are most useful as discriminator properties in tagged unions.

Deriving constrained types​

System types like string and number are sealed: you cannot add validators to them. To create a constrained variant, call .derive():

const Age = number.derive('Age')
const Name = string.derive('Name')

derive(name?, schema?) creates a new type that inherits the base type's validators and can have more added. The new type appears in the schema under the given name.

You can chain constraint methods directly on the returned type:

const Specialization = string
  .derive('Specialization')
  .oneOf(['Surgeon', 'Cardiologist', 'Internist'])

const PositiveAge = number
  .derive('PositiveAge')
  .positive
  .greaterThan(0)
  .lessThan(150)
