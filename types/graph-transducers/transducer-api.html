Transducer API

The Transducer class is a fluent builder that assembles processor chains without requiring you to implement IProcessor directly. Most data processing tasks can be expressed entirely through this API.

Creating a transducer​

import { transducer } from '@aelastics/types'

const tr = transducer()

transducer() returns a new Transducer builder. You chain pipeline steps onto it, then call a terminator to get the final IProcessor.

Pipeline steps​

Each method below returns this, so you can chain them freely. Steps run in the order they are added. A traversal step (dftMap or dftReduce) must appear in the chain for any operation that needs to visit child nodes.

See Pipeline Chain Rules for detailed rules on ordering and valid combinations.

API rename

The current source exposes recurse('makeItem') and recurse('accumulate'). These will be renamed to dftMap() and dftReduce() in an upcoming release.

dftMap()​

Drives depth-first graph traversal in bottom-up construction mode. Each node's result is derived from its children's results. Use this for conversions, transformations, DTO serialization, and instance creation.

transducer().dftMap()

dftReduce()​

Drives depth-first graph traversal in accumulation mode. A single accumulator is threaded through the traversal. Use this for collecting values: counts, sums, flat lists, or any fold over the graph.

transducer().dftReduce()

map(f)​

Transforms the value at each node.

transducer()
  .dftMap()
  .map((item, node) => ({ ...item, label: node.propName }))

f receives the current node value and the Node context object.

filter(f)​

Skips nodes where f returns false. The node is excluded from the output.

transducer()
  .dftMap()
  .filter((item, node) => item !== null)

validate()​

Attaches validation errors to each node. The output mirrors the input structure with @hasErrors and @errors fields added where validation fails.

transducer().dftMap().validate()

newInstance(initValues?, generateID?)​

Creates a new typed instance, optionally seeded with initValues as a template. Pass a generateID function to control how identifiers are assigned.

transducer().dftMap().newInstance({ name: 'default' })

toDtoGraph()​

Converts a typed instance to the graph DTO format — a flat, reference-based representation suitable for serialization or transport.

transducer().dftMap().toDtoGraph()

fromDtoGraph()​

Converts a graph DTO back into a typed instance.

transducer().dftMap().fromDtoGraph()

processAnnotations(annot)​

Applies an annotation during traversal. The annotation is invoked at each node that carries the relevant annotation metadata.

transducer().dftMap().processAnnotations(myAnnotation)

do(Ctor, ...args)​

Attaches any custom IProcessor constructor to the chain.

transducer().dftMap().do(MyProcessor, extraArg)

Ctor must have signature new (xfNext: IProcessor, ...args: any[]): IProcessor. See Custom Processors for how to build one.

doIf(condition, Ctor, ...args)​

Conditionally attaches a processor. If condition is false, the step is skipped entirely and the chain continues unchanged.

transducer()
  .dftMap()
  .doIf(process.env.NODE_ENV !== 'production', DebugLogger)

Terminators​

A terminator ends the pipeline and returns an IProcessor ready to pass to type.transduce(). Call exactly one terminator per pipeline.

doFinally(processor)​

Composes all pipeline steps and attaches processor as the terminal reducer. This is the most common terminator.

const tr = transducer()
  .dftMap()
  .validate()
  .doFinally(naturalReducer())

reduce(stepFn, initValue)​

Builds a custom terminal reducer from a plain step function.

const tr = transducer()
  .dftReduce()
  .reduce((acc, node, item) => acc + item.value, 0)

count()​

Returns a processor that counts the number of nodes visited.

const tr = transducer().dftReduce().count()

sum()​

Returns a processor that sums numeric node values.

const tr = transducer().dftReduce().sum()

Built-in reducers​

These are passed as arguments to doFinally().

ReducerBehaviour
naturalReducer()Builds an output that mirrors the input structure. Use for transformations where the shape is preserved.
identityReducer()Returns the last processed value as-is. Use when the final processor already produces the complete result (e.g. toDtoGraph).
stepperReducer()Accumulates results into a flat list. Use for collection-style operations.
import { naturalReducer, identityReducer, stepperReducer } from '@aelastics/types'

Running the pipeline​

type.transduce(processor, input, initObj?)
ParameterDescription
processorThe IProcessor returned by a terminator.
inputThe value to traverse. Pass undefined to traverse the type graph instead of an instance.
initObjOptional initial accumulator, used in 'accumulate' mode.

For end-to-end usage examples see Examples.
