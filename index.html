Synthesis

Synthesis is a TypeScript monorepo for model-driven software engineering. It provides an embedded domain-specific language (eDSL) for defining metamodels, constructing model instances with JSX, and writing model-to-model transformations. Supporting libraries handle runtime type validation, reactive state management, and typed error handling. A CLI tool ties everything together for code generation workflows.

History​

The project began in March 2019 as dynamic-types on GitLab, a runtime type system for TypeScript inspired by io-ts. In March 2020 it moved to the private aelastics monorepo on GitHub, where the type system grew alongside new packages for reactive state management, model stores, and a JSX-based model transformation engine. In 2026 the libraries were extracted into this public Synthesis monorepo.
