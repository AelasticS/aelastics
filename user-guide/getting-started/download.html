Download

The synth CLI ships as a self-contained bundle per platform. Each bundle includes Node.js and all dependencies; nothing else needs to be installed on your machine.

Current version: v0.2.0. Release notes for every version are in the changelog, and the releases page lists all versions with their bundles.

PlatformArchitectureDownload
Linuxx64synth-v0.2.0-linux-x64.tar.gz
Linuxarm64synth-v0.2.0-linux-arm64.tar.gz
macOSIntel (x64)synth-v0.2.0-darwin-x64.tar.gz
macOSApple Silicon (arm64)synth-v0.2.0-darwin-arm64.tar.gz
Windowsx64synth-v0.2.0-win32-x64.tar.gz
Platform support in v0.2.0

The Linux bundles are validated end to end. The macOS and Windows bundles are published but carry a known limitation: the release is built on a Linux runner and includes a platform-specific transpiler binary (esbuild), so importing and running model files may fail on those platforms in this version. macOS and Windows users can build from source instead, which works everywhere. Fully native bundles are planned for a future release.

After downloading, continue with Installation: extract the archive and add synth/bin to your PATH.
